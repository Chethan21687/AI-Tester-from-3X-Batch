# PythonProgramsAI

Python learning programs, numbered in the order they were written.

## Contents

| Range | Topics |
|---|---|
| 01–07 | Keywords, identifiers, variables, comments, data types |
| 08–12 | Arithmetic, BODMAS, multiple variables, print formatting |
| 13–19 | Literals, multiline comments, built-in functions, user input, strings |
| 20–25 | Literals, string quoting, arithmetic / comparison / logical operators |
| 26–27 | Ternary operator |
| 28–31 | `if` / `elif` / `else` conditions, grade calculation |

## Running

Each file is standalone:

```bash
python python_31_Grade_Calculation.py
```

Files that call `input()` (e.g. `python_17`, `python_27`, `python_31`) expect
values typed on stdin.

Requires Python 3.x. No third-party dependencies.
