Meet TestForge  the AI Test Analyst I built end-to-end 🧪

As a QA professional, I know the most tedious part of testing is turning requirements into test cases by hand. I wrapped it in a Streamlit app where testers review everything in a clean table, mark each case Pass/Fail/Blocked, and export the suite as a Word document. Building it meant owning the full journey — integrating LLMs, debugging environment and token limits, and refining the UI from real usage. The result is a complete tool: requirements file in, export-ready test suite out.
