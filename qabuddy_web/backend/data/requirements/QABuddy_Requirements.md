# QABuddy — Enterprise Requirement Specification

This document defines the artifacts and repositories used by the QABuddy AI-powered QA Knowledge Platform.

## 1. Selenium Repository
Official GitHub: https://github.com/SeleniumHQ/selenium
Purpose: Java Selenium automation framework using TestNG, Maven, POM, utilities, reports, Jenkins integration and reusable libraries. AI can explain code, generate automation and compare implementations.

## 2. Playwright Repository
Official GitHub: https://github.com/microsoft/playwright
Purpose: Python Playwright framework with Pytest, Page Objects, Fixtures, Reports, Logging, API integration and utilities. AI generates Playwright tests, fixes locators and explains framework.

## 3. VWO Project
End-to-end automation for login, dashboard, reports, heatmaps, funnels, API validation and regression.

## 4. Test Case Repository
Approx. 5000 manual and automated test cases in CSV, XLSX and JSON. Includes Test ID, steps, expected result, priority, severity, automation status and sprint mapping.

## 5. Jira Project
Project Key: QAB. Contains Epics, Stories, Tasks, Bugs, Production Defects, Sprints and Releases.

## 6. Company Documents
QA Guidelines, Automation Standards, Engineering Handbook, Coding Standards, Release Checklist, README.md, Architecture.md and deployment guides.

## 7. Figma (Phase 2)
Wireframes, ER Diagrams, User Guides, UI flows and prototypes.

## 8. Meeting Notes & Recordings
Sprint planning, retrospectives, standups, client meetings and recording transcripts.

## 9. Lucid Charts
Architecture, deployment, API flow, database ERD and CI/CD diagrams exported as text/PDF.

## 10. Requirement Documents
PRD, BRD, FRD and SRS PDFs describing business, functional and technical requirements.

## 11. Jenkins
Pipeline logs, console output, HTML reports, Allure reports, screenshots and build history.

## 12. AI Capabilities
RAG search, repository Q&A, Jira analysis, test generation, Playwright generation, Swagger validation, meeting summarization, build analysis.
